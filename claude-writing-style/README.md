# claude-writing-style

Mẫu `CLAUDE.md` để Claude Code soạn tin Teams/email bằng tiếng Việt theo văn phong chuyên nghiệp trong môi trường CNTT, có xưng hô đúng vai vế.

## Dùng
1. Chép `CLAUDE.md.example` thành `CLAUDE.md` ở thư mục dự án (hoặc thư mục cha), rồi thay các `<...>` bằng thông tin thật.
2. Claude Code tự nạp `CLAUDE.md` khi mở phiên trong thư mục đó.

## Lưu ý bảo mật
Repo này công khai. Chỉ commit file `.example` với placeholder. Không ghi họ tên thật, năm sinh, tên dự án hay hệ thống nội bộ vào repo. Bản `CLAUDE.md` đã điền thông tin thật chỉ giữ trên máy.
